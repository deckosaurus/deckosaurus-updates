Deckosaurus 0.2.12

About knows your channel

  • About now shows which release channel you are subscribed to and what the update feed says about the build you are running — for example "0.2.12 (13) is on canary since 23 Sep" — with a link to these release notes.
  • Preferences ▸ Updates carries the same line under "Last checked", so "You're up to date" is never ambiguous again.
  • A build that is not in the feed, an unreachable feed, or a local development build each say so plainly.

Smaller things

  • Every release now ships with notes; the update dialog will no longer be blank.
