Deckosaurus 0.3.5

Anonymous usage statistics, on by default, off in one click. Deckosaurus now sends three small signals — that it launched (version, channel, macOS version, processor), that an update check ran, and that an update installed — with a random install id and nothing else. No names, paths or content, ever, and the address a request comes from is never kept. The first launch shows a one-line notice before anything is sent.

  • Preferences ▸ Updates has the "Share anonymous usage statistics" switch and a link to the privacy policy; turning it off deletes the install id.
  • About links the privacy policy beside the release notes.
  • The policy itself: https://updates.deckosaurus.com/privacy.html — questions to privacy@deckosaurus.com.
