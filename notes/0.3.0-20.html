Deckosaurus 0.3.0

A second coding agent: OpenRouter

  • OpenRouter joins Claude Code. One API key, almost any model — enter it in Preferences ▸ Coding Agents ▸ OpenRouter and press Check connection.
  • Browse all models in their own window: search, filter by free/tools/vision/reasoning/context length, sort, star the ones you use, and read each model's limits before you pick it.
  • Choose the agent per workspace — in New Workspace, or later in the workspace's settings — and, for OpenRouter, the model too. The chat header shows what is running and lets you switch.
  • Your OpenRouter key is stored only in your login Keychain. The app never logs it and never sends it anywhere but OpenRouter.

Also in this release

  • Development builds are badged with their instance so they can never be mistaken for the installed app, and each keeps its own data.
  • About has a copy button for the version line — handy for bug reports.
  • New Workspace's Options group is a plain section; the Search sidebar says how many files matched; release notes render emphasis correctly.
