Deckosaurus privacy policy

Last updated 2026-09-24.

Deckosaurus sends a small amount of anonymous usage telemetry, on by default, that you can turn off at any time. This page says exactly what is sent, when, and how to stop it.

What is sent

Three events, each with a fixed, small set of fields — nothing beyond what is listed here:

  • launch — sent once per app launch: the app version, the build number, the update channel (stable, beta, or canary; a developer's local build sends nothing), the macOS version, and the processor type (arm64 or x86_64).
  • update.checked — sent after Sparkle finishes an update check, scheduled or manual: the result (up-to-date, update-found, or error).
  • update.installed — sent on the first launch after an update installs: the build you upgraded from and the build you upgraded to.

Every event also carries a random install id and a timestamp. That is the whole shape — there is no free-text field, and no event ever carries a file path, a workspace name, a project name, or anything you have typed.

It is anonymous

The install id is a random value generated on this Mac, with no connection to your name, your Apple ID, or any other account. We do not retain the IP address a request arrives from — our Worker never reads it, and nothing downstream of it is asked to. There is no way for us to connect an event back to a specific person from the data it carries.

How to turn it off

Preferences ▸ Updates has a Share anonymous usage statistics toggle, on by default. Turning it off stops every future event immediately, and deletes the random install id from this Mac — the next time you turn it back on, a fresh id is created rather than the old one being reused.

The update feed and downloads

Checking for updates and downloading them both go through updates.deckosaurus.com, which is served through Cloudflare. Cloudflare counts requests to that host as ordinary web traffic and processes them as a content delivery network under its own privacy policy; we see request counts by path and country, never who made them. No account is needed to read or download the app, and this is separate from the usage telemetry described above.

Retention

Raw telemetry events are kept for 90 days, then deleted. Aggregated counts derived from them (for example, "how many installs checked for an update this week") may be kept longer.
